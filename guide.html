1. AR-Xってなに？

AR-Xは、iPhoneやiPadで「音楽をつくる」ためのアプリです。ピアノやギターがなくても、画面をさわるだけで、ドラムやメロディの音をならせます。

たとえるなら、おとのレゴブロックです。ドラムのブロック、メロディのブロック、シンセ（ふしぎな音を出す楽器）のブロックをならべて、自分だけの曲をつくります。

できること：

  • ドラムをならす（ドン・タン・チッチッ）
  • メロディをならべて、くりかえしならす（シーケンサー）
  • シンセの音色をかえる（やわらかい音、とがった音など）
  • エフェクトでおもしろい音にする（XYパッドを指でなぞる）
  • つくった曲をほぞんして、あとでよびだす
  • 自分の演奏を録音する
  • MIDIキーボードや、ほかの音楽アプリとつなぐ

2. はじめて音を出そう

まずは3つだけ。これで音がなります。

  1. アプリをひらく。 ホーム画面の AR-X をさわります。このとき、iPhoneの「こうどうスイッチ（マナーモード）」をオフにして、音量をあげておきましょう。
  2. 「PLAY」ボタンをタップ。 ボタンが光って、リズムがなりはじめます。
  3. もう一度「PLAY」をタップ。 光が消えて、音がとまります。

テンポ（はやさ）をかえたいときは、BPMと書いてあるマルいツマミ（ノブ）を指でまわします。右にまわすとはやく、左にまわすとゆっくりになります。

こまったら：音がでないときは、「14. こまったときは」をみてね。

3. 画面のなまえ

画面の左のふちには、どのページでも同じボタンがならんでいます。リモコンのようなものです。ページをかえても、ここはいつもいっしょです。

ボタン・ノブなにをする？
PLAYスタートとストップ（押すたびに切りかわる）
BPM（ノブ）テンポ。数字は表示窓で確かめられる
KICK / SNARE / HATドラムのオン・オフ。光っている＝なる、消えている＝ミュート（だまっている）
SEQ A / SEQ Bメロディのオン・オフ。メロディは2つ（AとB）あり、べつべつに切りかえられる
PTN A / B / Cドラムのパターン（リズムの型）を3つからえらぶ
<PAGE / PAGE>ページをとなりへ進む・戻る
SEQ CTRL … DRUM EDIT見たいページへとぶボタン（6つ）
MIDI / REC EXPORTMIDIのページと、録音・書き出しのページ
XY PAD指でなぞって音をどんどんかえるパッド
FX1〜FX3 (EDIT / HOLD / MIX)エフェクト（音のおけしょう）の設定
BALANCE SYN-DRMシンセとドラムのどっちを大きくするか
USER A / B / C, SAVEつくった音をはこにしまう・とりだす
LINKほかのアプリとテンポをあわせる

ノブは、指でクルクルとまわすマルいつまみ。フェーダーは、上下にすべらせる棒です。ボタンは、ポンとタップします。

4. ページちず

AR-Xは、本のページのように8つのページでできています。左のボタンでとびます。

ページボタンここでできること
1SEQ CTRLメロディの高さ（PITCH）とオクターブを決める
2SEQ EDITメロディの強さ（V1/V2）、長さ（GATE）、ところどころの高さ（TRANSPOSE）
3SYN CTRLシンセのステップ（ON）と、音のゆらぐ（GRIDE）
4SYN EDITシンセの音色をくわしくつくる
5DRUM CTRLドラムのリズムをボタンでつくる
6DRUM EDITドラムの音をかえる（音の高さ・長さ・ひずみなど）
7MIDIMIDIの機械をつなぐ
8REC EXPORT録音と、プロジェクトの書き出し・読みこみ

ページのとび方は2つ。

  • 行きたいページのボタンを直接タップする。
  • <PAGE と PAGE> でとなりへ。ページ、1→2→3→4→5→6をぐるぐるまわります（MIDIとRECはこのボタンでは行けません）。

いまいるページのボタンだけが、光っています。

5. ドラムをならそう

ドラムは「DRUM CTRL」（ページ5）でリズムをつくり、「DRUM EDIT」（ページ6）で音をかえます。

リズムをつくる（DRUM CTRL）

  1. 「DRUM CTRL」ボタンをタップ。
  2. ボタンが4つの行にならんでいます。KICK（ドン）・SNR（タン）・CHH（閉じたハイハット、チッ）・OHH（開いたハイハット、チー）。
  3. 各てんに「1〜16」のボタンがあります。ボタンをタップすると、そのばしょで音がなるようになります（光る）。もう一度タップすると消えます。
  4. PLAYを押すと、1から16へと順番に音がなり、ぐるっともどってくりかえします。

たとえば、「1・5・9・13」にKICKをのせると、「ドン・ドン・ドン・ドン」という定番のリズムになります。

各ステップの下には小さな「ACC」ボタンもあります。これは「アクセント」のこと。ここを光らせると、その音が強めになります。

パターン A / B / C

リズムは3つまで別々にとっておけます。左の PTN A / PTN B / PTN C をタップすると、切りかえられます。Aは「ふつうのリズム」、Bは「にぎやかなリズム」というふうに使い分けると便利です。

音をかえる（DRUM EDIT）

「DRUM EDIT」ボタンで、ドラムごとにノブがあらわれます。KICK・SNARE・HI HATにはこんなノブがあります。

ノブどんなときにまわす？
TUNE音の高さ。右で高い音、左で低い音
DECAY音ののこる長さ。HI HATには開いた音用のO.DECAYもある
LEVELそのドラムの音の大きさ
DISTドラムの音を「ひずませる」スイッチ（ギュイーンと荒っぽくなる）
CRSHドラムの音を「ざらざら」にするスイッチ（クラッシャー）
FX1〜FX4エフェクトにどれだけおくるか

ページの右したには、みんなでつかう DISTORTION（ひずみ）と CRUSH（ざらざら）の設定があります。

  • DISTORTION：DRIVE（ひずみのつよさ）、LEVEL（音量）、HARD / MID / SOFT（ひずみのしゅるい）
  • CRUSH：FREQ、LEVEL、12BIT / 8BIT / 4BIT（数字がちいさいほどざらざら）

6. メロディをつくろう

メロディは「SEQ A」と「SEQ B」の2つを同時にならせます。ギターとベースのようなもので、左の「SEQ A」「SEQ B」ボタンで、それぞれオン・オフできます。

音の高さを決める（SEQ CTRL）

  1. 「SEQ CTRL」ボタンをタップ（ページ1）。
  2. PITCH（縦の棒）を上下にすべらせる。上にあげると高い音、下げると低い音です。
  3. + / − ボタンで、さらに1オクターブ（「ド」から次の「ド」までのぶん）、高く・低くできます。
  4. 4BIT PTN（ノブ）をまわすと、「どのタイミングで音をならすか」の型がかわります。右にまわすほど、なる数がふえる型になります。
  5. ノブのうえの小さなランプ（LED）で、いまどこをならすかが見えます。

ことばでいうと、PITCHは「どの音か」、4BIT PTNは「いつならすか」です。

音のつよさと長さを決める（SEQ EDIT）

「SEQ EDIT」ボタン（ページ2）で、もう少しこまかくなおせます。

これなにをする？
V1 / V2 ボタンその音をどれだけ強くならすか（ベロシティ）を選ぶ
V0 / V1 / V2 ノブ強さの大きさそのものを決める
GATE（縦の棒）音の長さ。上げるとのびて、下げるとぷつっと短くなる
TRANSPOSE（ノブ）4小節ごとに、メロディ全体の高さをいっせいにずらす

TRANSPOSEを使うと、同じメロディでも「1小節目は普通、　3小節目はすこし低く」のように、変化をつけられます。

ヒント：SEQ AとSEQ Bをすこしちがう高さにすると、きれいなハーモニー（重なりの音）になります。

7. シンセの音色をかえよう

シンセは、ふしぎな音をつくる楽器です。AR-Xは「FM（エフエム）」というしくみで、キラキラした音や、金属のような音をつくれます。

FMってなに？

「メインの音」を、「ゆらし役の音」でゆらすと、ぶくぶくしたふしぎな音になります。ブランコの上で、もう一人が鎖をゆらすと、動きが複雑になるのと似ています。

  • CAR（キャリア）：メインの音
  • MOD（モジュレーター）：ゆらし役の音

ページ3：SYN CTRL

  • ON（ボタン）：8つのステップで、そのばしょの設定を使うかどうか。
  • GRIDE（グライド）：音がすーっと滑らかにつながる。ヘビがすべるような音になります。
  • GRIDE TIME / MGR TIME（ノブ）：すべるのにかかる時間。
  • STEP SEQ / LOOP X2 / AS 8TH：くりかえしのかたちをえらぶスイッチ。

ページ4：SYN EDIT

ここが「音色工房」です。ノブがたくさんあるので、はじめはここだけさわるだけでも、十分あそべます（おすすめは TUNE・MOD IDX・ATK・REL）。

ノブ・ボタンやくわり
TUNE音の高さをぜんたいにずらす
GAIN音の大きさ
MOD IDXゆらし役のおおきさ（あげるとキラキラ・ザラザラする）
MOD FBKゆらし役に自分の音をもどして、ドロドロにする
MOD RATE / CAR RATEゆらし役・メインの音の高さの比
SIN / TRI / SQR / SAW音の形。SINはやわらかい、SQRとSAWはとがっている
ATK / DEC / SUS / REL音の始まりと終わりの形（下を見てね）
HI PASS / LO PASS高い音・低い音をけずる
SERIES / PARALLELゆらし役をメインにかけるか、ふたりを並べて鳴らすか
LFO RT / DEP / DELビブラートのようなゆらぐ。速さ・おおきさ・始まるまでの時間
UNISON ON同じ音をちょっとずつずらして重ね、分厚くする
4/8/16/32 BITわざとざらざらにする（数字が小さいほどざらざら）
FX1〜FX4エフェクトへちょっと送る

ATK / DEC / SUS / REL ってなに？ ピアノは「ポンっとなって、すぐ小さくなる」、バイオリンは「すーっと大きくなって、ゆっくり消える」。その「形」を決めるのがこの4つです。

  • ATK（あたっく）：音が大きくなるまでの時間
  • DEC（でぃけい）：大きい音から、ちょうどよい大きさに落ちる時間
  • SUS（すてぃん）：のばしているあいだの音の大きさ
  • REL（りりーす）：鍵を離したあと、消えるまでの時間

こわれたところはないので、いろいろまわして、おもしろい音を探してみてください。

8. エフェクト（XYパッド）であそぼう

エフェクトは、音にかける“魔法”です。こもった音にしたり、やまびこのようにエコーをつけたりできます。左のふちにある四角いパッドが「XY PAD」です。

つかいかた

  1. FX EDIT ボタンで、あそぶエフェクトをえらぶ（FX1〜FX4）。
  2. パッドを指でさわる。横（X）と縦（Y）の位置で、音がかわります。
  3. FX MIX ノブで、エフェクトのかかりぐあいをえらぶ。
  4. FX HOLD を光らせると、指をはなしてもその位置のままになります。

4つのエフェクト

エフェクトどんな音？横（X）縦（Y）
FX1こもった音（ローパスフィルター）右で明るい音、左でこもった音上でクセがつよくなる
FX2ジェット機のようなサーッという音（フランジャー）ゆれるはやさよりつよくなる
FX3やまびこ（ディレイ）エコーの間隔エコーのくりかえしのながさ
FX4お風呂やホールのようなひびき（リバーブ）ひびきのながさ音のやわらかさ

どの楽器にかける？

ドラムとシンセのページ（DRUM EDIT・SYN EDIT）にある FX1〜FX4 のボタンで、かけたい楽器を選びます。光っているエフェクトに、その楽器の音が届きます。

9. BPMとバランス

BPM（はやさ）

BPMは「1分間にドンを何回うつか」という数です。数字が大きいほど、はやい曲になります。

  • 左の BPMノブ をまわす。
  • できるはやさは 40 から 240 まで。はじめは 120 です。
  • いまの数字は、すぐ上の数字の表示で確かめられます。

ゲームのキャラでいうと、「あるくはやさ」をきめるものです。

BALANCE SYN-DRM

シンセ（SYN）とドラム（DRM）の、音の大きさのつりあいをとるノブです。シーソーのように、どちらかを大きくすると、もういっぽうが小さくなります。

  • 真ん中：シンセとドラムがちょうどよいバランス
  • 左にまわす：ドラムが大きく聞こえる
  • 右にまわす：シンセが大きく聞こえる

このノブはどのページにもあるので、いつでもすぐにつかえます。

10. 保存とよびだし

つくった音やリズムは、「トランク」のようにしまっておけます。すこしのきまりを覚えると、むずかしくありません。

カギをかんたんにいうと

  • USER A / USER B / USER C：3つの「ことばこ」。はこをえらぶボタンです。
  • スロット 1・2・3・4：はこの中の、おへやの番号です。、1つのはこに4つ入ります。
  • SAVE：「いまのページの内容をしまう」ときに押すボタン。

ただし、ページごとに別々に保存されます。たとえば、DRUM CTRLで保存したものは、DRUM CTRLのときだけよびだせます。

保存する

  1. 保存したいページをひらく。
  2. USER A / B / C のどれかをえらぶ。
  3. SAVE をタップ。ボタンが光ります。
  4. 保存したい番号（1〜4）をタップ。
  5. 「保存しますか？」と聞かれるので、YES をタップ。NOは「ここにはしまわない」、CANCELは「やめる」です。

SEQ CTRL / SEQ EDIT では、「SEQ A を保存する？」ともう一度ききます。うっかり間違えて上書きしないためです。

【だいじ】すでに入っている番号に保存すると、もとの内容は消えます。大切な音は、あいている番号を使いましょう。

よびだす

  1. よびだしたいページをひらく。
  2. USER A / B / C をえらぶ。
  3. SAVEを押さずに、番号（1〜4）をタップ。

「空っぽ」と出たら、その番号にはまだ何も入っていません。

アプリには、はじめからデモ用のメロディやシンセ音色が4つ入っています（USER A）。上書きしてもかまいません。

プロジェクトをファイルにする（EXPORT / IMPORT）

「REC EXPORT」ページには、EXPORT と IMPORT ボタンがあります。

  • EXPORT：いまの作品をファイルにして、シェアのメニューから保存・送信できます。
  • IMPORT：保存したファイルを選んで、もとにもどします。

アプリを入れ直すときや、ともだちに作品をわたすときに便利です。

11. ほかのアプリとテンポをあわせる（Ableton Link）

Linkは、「みんなで同じテンポでえんそうする」ためのしくみです。バンドで、ドラムの人をみんなが見てリズムをそろえるのと同じです。同じしくみに対応した他のアプリや、ほかのiPhone・iPadと、テンポやスタートをそろえられます。

つかいかた

  1. アプリを、同じWi‑Fiにつながっている端末といっしょに使う。
  2. 左の「LINK」ボタンをタップ。
  3. Linkの設定画面がひらくので、スイッチをオンにする。
  4. 初めてのとき、iPhoneから「ローカルネットワークのアクセス」をこうしていいかと聞かれたら、「許可」をえらぶ。
  5. なかまをさがしているあいだは、「Ableton Link: searching for peers…」と出ます。見つかると、テンポが自動でそろいます。

オフにしたいときは、もう一度「LINK」をタップします。

こんなときは大丈夫

  • ほかになかまがいないときでも、アプリはふつうにつかえます。
  • Linkをオフにしても、再生中の音はそのまま続きます。
  • Linkを使っているときは、PLAYを押すと、ほかのアプリとビート（拍）の位置をあわせて始まります。

12. MIDIキーボード・コントローラーをつなぐ

MIDIは、楽器やコントローラーとアプリをつなぐ、“言葉”のようなものです。ノブやフェーダーがついたいどうきをつなげると、画面のノブを、本物のつまみでうごかせます。

つないで、紐づける（LEARN）

  1. コントローラーをiPhone・iPadにつなぐ。
  2. 「MIDI」ボタンでMIDIページをひらく。
  3. 「MIDI」ページのリストから、つないだ機械をえらぶ。「Connected」と出ればOKです。
  4. LEARN をタップ（ボタンが光る）。
  5. 画面の赤いボタン・ノブ・フェーダーをタップ。
  6. 本物のコントローラーをうごかす。「learned（覚えた）」とでれば紐づけ完了です。

これをくりかえせば、好きなだけ紐づけられます。紐づけは、アプリをとじても覇えています。

らくに紐づけする（NAV LEARN）

NAV LEARN を押すと、アプリが「これをうごかして」「次はこれ」と順番に教えてくれます。コントローラーのつまみを順番に動かすだけで、たくさん紐づけできます。やめたいときは、もう一度 NAV LEARN を押します。

やり直す

CLEAR ALL を押すと、紐づけがぜんぶ消えます。

ふしぎなことにびっくりしないで

コントローラーのツマミをうごかしても、すぐには音がかわらないことがあります。これは、画面のノブが急にジャンプしないようにする安全のしくみです。ツマミを画面のノブがいる位置まで動かすと、つながって動き始めます。

「MIDI MONITOR」のところに、いま届いている信号が表示されるので、うまくつながっているか確かめるのに便利です。

13. 録音 (REC)

つくった音を、そのまま音のファイル（WAV）にして残せます。カセットテープに録音するようなものです。アプリで鳴っている音をそのまま録るので、マイクはいりません。

やりかた

  1. 「REC EXPORT」ボタンで、録音ページをひらく。
  2. 録音する長さをえらぶ。MANUAL（自分で止める）、1 BAR、2 BARS、4 BARS、8 BARS、16 BARS。
  3. PLAYで音をならす。
  4. RECをタップ。「● REC…」と、いまの秒数が出ます。
  5. MANUALのときは、もう一度 REC をタップすると止まります。小節をえらんだときは、その長さで自動で止まります。
  6. 止まると、WAVファイルができます。

「1小節」は「4拍」のことです。BPMが120なら、1小節は2秒です。

テンポやバランスを決めてから録音すると、やり直しがすくなくてすみます。

14. こまったときは

こまったことためしてみてね
音がでないiPhoneの音量をあげる。横のスイッチ（マナーモード）をオフにする。PLAYを押したか確かめる。KICK・SNARE・HAT・SEQ A・SEQ Bが光っているか見る（消えているとだまっています）。
ドラムだけ、またはシンセだけが小さいBALANCE SYN-DRM ノブが片方によりすぎていないか確かめて、真ん中にもどしてみる。
ホーム画面にもどると音が止まるiPhoneの「設定」→ AR-X → 「バックグラウンド再生」がオンになっているか確かめる。オンなら、ホーム画面にもどっても鳴り続けます。オフなら、アプリをはなれたところで止まります（バッテリーをつかいません）。
音がときどきとび・リズムがずれるほかのアプリをとじる。端末があつくなっていないか確かめる。これでもだめなら、アプリをいったんとじて、もう一度ひらく。
シンセの音だけが出なくなったアプリをいったんとじて、もう一度ひらく。それでも直らないときは、いつ・どのページで起きたかをつたえてください。
Linkでなかまが見つからない同じWi‑Fiにつながっているか確かめる。iPhoneの「設定」で、AR-Xの「ローカルネットワーク」がオンか確かめる。LINKを一度オフにして、もう一度オンにする。
MIDIの機械が見つからないケーブルをつなぎ直す。MIDIページで機械をえらび直す。
