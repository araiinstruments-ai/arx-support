よくあるご質問

対応しているMIDIコントローラーはありますか？
MIDI Learn機能で任意のMIDIコントローラーをマッピングできます。特にKORG nanoKONTROL2に最適化されています。
Ableton Linkには対応していますか？
対応しています。LINKボタンをオンにすると、同じWi-Fiネットワーク上のAbleton Liveや他のLink対応アプリと、テンポと再生・停止を同期できます。初回は「ローカルネットワーク」へのアクセス許可が求められるので、許可してください。接続できない場合は、iPhone／iPadの「設定」→「プライバシーとセキュリティ」→「ローカルネットワーク」で、AR-Xがオンになっているか確認してください。
作成したプロジェクトのバックアップはできますか？
アプリ内のEXPORT機能でプロジェクトをファイルとして書き出し、共有・保存できます。IMPORT機能で読み込みも可能です。
演奏を録音できますか？
REC機能で実際の音声出力をそのままWAVファイルとして書き出せます。

Frequently Asked Questions

Which MIDI controllers are supported?
You can map any MIDI controller using MIDI Learn. The app is specifically optimized for the KORG nanoKONTROL2.
Does it support Ableton Link?
Yes. Turn on the LINK button to sync tempo and start/stop with Ableton Live and other Link-enabled apps on the same Wi-Fi network. The first time, iOS asks for Local Network access; please allow it. If it can't find other apps, open Settings → Privacy & Security → Local Network on your iPhone or iPad and check that AR-X is switched on.
Can I back up my projects?
Yes — use the in-app EXPORT feature to save a project as a file, which you can share or store. Use IMPORT to load it back in.
Can I record my performance?
Yes, the REC feature captures the actual audio output and exports it as a WAV file.

最終更新日：2026年10月8日

AR-X Groovebox（以下「本アプリ」）は、開発者（以下「当方」）が提供するiOS向けアプリケーションです。本ポリシーは、本アプリにおける個人情報の取り扱いについて説明するものです。

収集する情報

本アプリは、ユーザーの個人情報を収集しません。

  • 音声処理・シーケンサー・シンセサイザーの動作は、すべて端末内（ローカル）で完結しており、ユーザーのデータを当方のサーバーへ送信することはありません。
  • 本アプリには、外部の分析ツール（アナリティクス）や広告SDKは組み込まれていません。
  • アカウント登録・ログイン機能はなく、ユーザーを識別する情報の収集も行いません。

Webフォントについて

本アプリは、画面表示用のフォントをGoogle Fontsから取得する場合があります。この取得の際、インターネット通信の仕組み上、IPアドレスなどの通信情報がGoogleに送信されることがあります。当方がこれらの情報を受け取ることはありません。取得できない場合は、代替フォントで表示されます。

MIDI・ローカルネットワーク通信について

本アプリは、外部MIDIコントローラーとの接続、および同一Wi-Fiネットワーク上の他のLink対応アプリ（Ableton Liveなど）とのテンポ・再生状態の同期（Ableton Link）のために、ローカルネットワーク通信を利用します。この通信は端末間の演奏データ・同期情報のやり取りに限られ、個人情報の収集・外部への送信は行いません。初回のLink利用時に、iOSがローカルネットワークへのアクセス許可を求めます。

保存データ

ユーザーが作成したプロジェクトデータ（パターン、音色設定等）は、ユーザー自身の端末内、またはユーザーがEXPORT機能を用いて明示的に書き出したファイルとして、ユーザー自身の管理下に保存されます。当方がこれらのデータにアクセスすることはありません。

第三者への提供

本アプリは、いかなる個人情報も第三者へ提供・共有しません（そもそも収集を行っていないため）。

お子様のプライバシーについて

本アプリは特定の年齢層を対象とした個人情報の収集機能を持たないため、13歳未満のお子様を含め、すべてのユーザーについて個人情報を収集しません。

本ポリシーの変更

本ポリシーの内容は、法令の変更やアプリの機能追加に伴い、予告なく改定される場合があります。重要な変更がある場合は、本ページ上でお知らせします。

AR-X Groovebox (the "App") is an iOS application provided by its developer ("we" / "us"). This policy explains how the App handles personal information.

Information We Collect

The App does not collect any personal information from its users.

  • All audio processing, sequencing, and synthesis run entirely on-device (locally). User data is never sent to our servers.
  • The App does not include any third-party analytics tools or advertising SDKs.
  • There is no account creation or login, and no user-identifying information is collected.

Web Fonts

The App may download its display fonts from Google Fonts. As with any internet request, technical information such as your IP address may be sent to Google when this happens. We do not receive this information. If the fonts cannot be downloaded, the App shows fallback fonts instead.

MIDI and Local Network Communication

The App uses local network communication to connect to external MIDI controllers and to sync tempo and play state (Ableton Link) with other Link-enabled apps, such as Ableton Live, on the same Wi-Fi network. This communication is limited to performance and sync data exchanged between devices, and does not involve collecting or transmitting personal information. The first time you use Link, iOS asks for permission to access the local network.

Stored Data

Project data created by the user (patterns, sound settings, etc.) is stored on the user's own device, or in files the user explicitly exports using the EXPORT feature, and remains under the user's control at all times. We do not have access to this data.

Sharing with Third Parties

The App does not share any personal information with third parties, since none is collected in the first place.

Children's Privacy

Because the App has no feature that collects personal information from any user, it does not collect personal information from children under 13 or from any other user.

Changes to This Policy

This policy may be updated without prior notice to reflect changes in law or app functionality. Any material changes will be announced on this page.
